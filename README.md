# Stille

**Weniger Ablenkung. Mehr Raum für das Wesentliche.**

An independent, open-source focus app for intentional work and restorative breaks.

[MIT licensed](LICENSE) · Early development

</div>

## The idea

Stille helps you protect your attention without turning productivity into another source of pressure. Set boundaries around distracting content, work in focused sessions, and make room for breaks.

## Planned capabilities

- **Website and app blocking:** choose which distractions to keep out of a focus session.
- **Focus timer:** Pomodoro-style work and break intervals, with room for your own rhythm.
- **Recurring schedules:** protect selected weekdays or time windows, including all-day boundaries.
- **Clear controls:** understand what is blocked, when it ends, and how your rules behave.
- **Local-first design:** keep focus settings on your device by default.

These are product goals, not implemented features. This repository currently contains the initial project and branding documents; there is no runnable app yet. The implementation stack has not been selected.

## Brand

Stille means **silence** in German. The visual identity pairs a calm interface with a vivid purple accent: **`#A020FF`**.

See [the brand guide](docs/brand.md), [color tokens](branding/tokens.css), and [draft mark](branding/mark.svg).

## Independent implementation

Stille is a new project, not an Abstand fork. We may explore the same general ideas—focus sessions, blocking distractions, and scheduled breaks—but its implementation, interface, and assets will be developed independently.

Do not copy or adapt code or assets from AGPL-licensed projects into this MIT-licensed repository. Use public platform documentation and appropriately licensed dependencies instead.

Stille is not affiliated with existing products using the same or similar names. The working name has not received trademark clearance.
